คลังเจ๋งแจ๋ว v4 — ระบบบัญชีหลายเครื่อง
เวอร์ชัน: 25 กันยายน 2569

สิ่งที่เพิ่มใน v4
- โลโก้คลังเจ๋งแจ๋วในหน้าเข้าสู่ระบบและระบบร้าน
- หน้าสร้างบัญชี/เข้าสู่ระบบด้วยอีเมลและรหัสผ่าน
- ปุ่มลืมรหัสผ่าน
- หน้าตั้งค่า Firebase ในตัวเว็บ: วาง Firebase Web config ได้เอง แล้วเว็บจะรีโหลดเพื่อเชื่อมต่อ
- ซิงก์ข้อมูลร้าน สินค้า รายรับ-รายจ่าย และการแบ่งเงินกับ Firestore ตามบัญชีผู้ใช้
- แบ่งเงินเป็นเงินลงทุน / เงินส่วนตัว / เงินยังไม่จัดสรร
- พื้นหลังมังกร SVG แบบเคลื่อนไหว

วิธีเปิดบัญชีออนไลน์หลายเครื่อง
1. ไปที่ Firebase Console และสร้าง Project
2. เปิด Authentication > Sign-in method > เปิด Email/Password
3. สร้าง Firestore Database
4. ไปที่ Project settings > Your apps > เพิ่ม Web app แล้วคัดลอก Firebase config
5. เปิดเว็บไซต์ > หน้าเข้าสู่ระบบ > กด “ตั้งค่าบัญชีออนไลน์ / Firebase”
6. วาง config แล้วกด “บันทึกและเชื่อมต่อ” เว็บจะรีโหลด
7. กด “สร้างบัญชี” แล้วสมัครด้วยอีเมล + รหัสผ่าน
8. นำไฟล์ firestore.rules ในชุดนี้ไปใช้เป็น Rules ของ Firestore เพื่อให้แต่ละบัญชีอ่าน/เขียนได้เฉพาะข้อมูลของตัวเอง

Firebase Web config ไม่ใช่ Service Account/private key และไม่ควรนำ private key มาวางในหน้าเว็บ

โหมดทดลอง
- ปุ่ม “ทดลองใช้ในเครื่องนี้” ยังใช้ได้โดยไม่ต้องตั้ง Firebase
- โหมดทดลองเก็บข้อมูลไว้เฉพาะเบราว์เซอร์เครื่องนั้น จึงไม่ซิงก์หลายเครื่อง
